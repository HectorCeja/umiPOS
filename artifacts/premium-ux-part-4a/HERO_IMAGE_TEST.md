# Hero Image Test

Login, Dashboard, Productos, Ventas, Caja, Perfil y Centro de Ayuda pueden funcionar como hero de nexo.com porque comunican propósito sin explicación externa, mantienen una acción dominante y usan datos honestos. Onboarding, Inventario, Equipo, Configuración y Reportes son apropiados para un caso de estudio por su densidad contextual. Clientes no se usa como hero mientras siga fuera del alcance; Flutter POS requiere una captura nativa futura.

## Behance / Dribbble

El caso completo es publicable en Behance por sistema, proceso y consistencia; no se evalúa por “likes” hipotéticos. Las pantallas aisladas de Login, Dashboard y Productos tienen suficiente foco para una pieza visual, pero la evidencia prioriza producto operable sobre una composición artificial.
