# Keynote Test

| Pantalla | ¿Keynote? | Qué se entiende en 5 segundos | Acción principal | Jerarquía / distracción |
|---|---|---|---|---|
| Login | Sí | Acceso a NEXO para operar el negocio | Iniciar sesión | Hero y formulario, sin competencia |
| Onboarding | Sí | Configuración guiada del negocio | Continuar el paso | Progreso domina; ayuda acompaña |
| Dashboard | Sí | Estado operativo de hoy | Abrir acción rápida | KPIs primero; contexto permanece discreto |
| Ventas | Sí | Consultar y resolver ventas | Seleccionar/buscar venta | Resumen antes de historial; diagnóstico cerrado |
| Caja | Sí | Control del turno de efectivo | Continuar estado válido | Sesión y siguiente acción dominan |
| Productos | Sí | Crear y administrar catálogo | Crear producto | Imagen/nombre antes de metadata |
| Inventario | Sí | Consultar existencia real | Elegir producto y ubicación | Selectores antes de saldos |
| Equipo | Sí | Personas, invitaciones y acceso | Invitar | Rol y correo dominan; ayuda lateral |
| Clientes | Adaptado | Capacidad futura, honestamente indicada | Ninguna acción falsa | El empty state evita promesas |
| Configuración | Sí | Ajustes del negocio | Guardar cambios | Agrupación por intención |
| Perfil | Sí | Identidad personal | Actualizar perfil | Avatar y nombre primero |
| Reportes | Sí | Lectura confirmada del periodo | Interpretar indicadores | Cifras antes de explicación |
| Flutter POS | Sí por evidencia previa | Operación de venta y turno | Acción financiera válida | Contenido crítico contenido |
| Centro de Ayuda | Sí | Buscar y retomar una guía | Buscar ayuda | Search primero, contenido después |

“Adaptado” no oculta un defecto: Clientes está fuera del alcance funcional actual y mostrar una keynote falsa violaría la honestidad del producto.
