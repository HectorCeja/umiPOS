# Competitive Analysis

## Método y fuentes

La comparación usa principios publicados por cada referente, no imitaciones visuales:

- [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines): jerarquía, armonía, consistencia y adaptación.
- [Linear — A calmer interface](https://linear.app/now/behind-the-latest-design-refresh): familiaridad, calma y fluidez.
- [Stripe app design](https://docs.stripe.com/stripe-apps/design): consistencia de plataforma y accesibilidad alta.
- [Notion shortcuts](https://www.notion.so/Notion-Cheat-Sheet-2195940e179280bf8e9bd00c2bdea06f): composición clara y acceso mediante teclado.
- [Arc keyboard shortcuts](https://resources.arc.net/hc/en-us/articles/20595231349911-Keyboard-Shortcuts): navegación y cambio de contexto rápido.
- [Raycast keyboard shortcuts](https://manual.raycast.com/keyboard-shortcuts): operación integral con teclado y acciones primarias previsibles.
- [Framer component practices](https://www.framer.com/help/articles/component-best-practices/): estados completos, responsive y detalles intencionales.
- [Vercel Web Interface Guidelines](https://vercel.com/design/guidelines): precisión tipográfica, unidades, números y consistencia Geist.

## Principios comparados

| Referente | Principio observable | Aplicación crítica a NEXO | Evidencia |
|---|---|---|---|
| Apple | El contenido domina y los controles lo elevan | Headings balanceados, acciones primarias inequívocas | Jerarquía por pantalla |
| Linear | Calma sin perder velocidad | Menos ruido técnico, transiciones breves | Ventas y Caja |
| Stripe | Precisión inspira confianza | Dinero tabular, consecuencias explícitas | Métricas y mutaciones |
| Notion | Claridad progresiva | Diagnóstico cerrado, ayudas reabribles | Disclosure compartido |
| Arc | Contexto visible y fluido | Organización/sucursal persistentes | Shell global |
| Raycast | La velocidad incluye teclado | Foco, búsqueda global y orden navegable | Navegación completa |
| Framer | Componentes responden desde el sistema | Cards, modales y breakpoints compartidos | Component Library |
| Vercel | Microprecisión sistémica | Números, shortcuts, labels y tablas | Capa benchmark Part 4A |

## Conclusión objetiva

NEXO supera al benchmark generalista en contexto operativo específico: tenant, sucursal, caja, inventario y permisos permanecen visibles sin exponer infraestructura. Pierde frente a productos maduros en datos longitudinales de producción, ecosistema y validación masiva; esos límites no se pueden resolver honestamente con decoración ni pertenecen a este pass.
