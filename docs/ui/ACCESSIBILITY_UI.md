# Accessibility UI

Objetivo: WCAG 2.2 AA. Login y Home tienen un H1, landmarks, labels, botones reales, navegación etiquetada, `aria-current`, live regions para mutaciones y skip link. El H1 visual de Home conserva el nombre accesible completo “Buenos días, …”.

El drawer móvil tiene trigger, `aria-expanded`, scrim cerrable y Escape. Focus usa tokens de contraste. Password reveal mantiene un control real. Reduced motion conserva feedback esencial y elimina ambiente.

Los gráficos decorativos exponen un nombre textual y no afirman una tendencia inexistente. Los estados vacíos explican fuente ausente y siguiente acción. Axe critical/serious debe permanecer en cero.
