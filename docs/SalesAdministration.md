# Sales Administration

Sales now renders inside the official global shell, uses contextual scrollspy, localized dates and human status labels. IDs and processing details remain progressively disclosed. It still cannot become a checkout surface.

La sección `/sales` es una consola administrativa conectada a Sales. Expone Overview, History, Detail, Open/Suspended, Refunds, Receipts, Exceptions, Timeline y diagnóstico. Emite intenciones; nunca calcula precios, impuestos, totales, stock, efectivo o variance. Sales conserva autoridad comercial; Inventory y Cash se muestran mediante relaciones de lectura allowlisted.

La venta manual queda deshabilitada por defecto. No se creó un POS web ni se aplicaron cambios derivados de UMI.
