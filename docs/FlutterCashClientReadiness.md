# Flutter Cash Client Readiness

Flutter uses the same OpenAPI commands and queries: Register selection, open/suspend/resume, movement, count/recount, approval, reconcile/close, timeline and summary. It stores idempotency keys across timeout/retry and displays authoritative states/minor-unit money. Session recovery is query-based. Open/close, posting, approval, transfer and reconciliation are always-online. Offline mutation, hardware opening and secure local custody require a future ADR. Layout may be native/adaptive while state and writing remain equivalent.
