# Support Diagnostic Bundle

`GetSaleDiagnosticBundle` entrega sale ID, branch, timestamp, correlation ID, API/app version, estado worker/outbox y tipos de evento. Nunca incluye cookies, tokens, passwords, device tokens, PAN/CVV, stacks, payloads completos o datos de otro tenant. Es seguro para adjuntar a ChatGPT, Codex o soporte después de revisión humana.
