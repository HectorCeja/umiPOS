# Receipt Model

Modelo inmutable, localizado y ajeno a impresión: snapshots Organization/Branch, folio, business date/timestamp, seller, líneas, descuentos/impuestos/totales, pagos/cambio, texto legal, locale y referencias. Su SHA-256 detecta manipulación. El mismo JSON alimentará Web, Flutter, PDF, email, impresora o UMI; drivers quedan fuera.
