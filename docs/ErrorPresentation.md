# Error Presentation

Primary messages answer: what happened, what is affected, and what the user can do. Internal route names, UUIDs, constraints, SQL and raw enums never become the headline. A stable reference may appear as secondary support information.

Forms use controlled es-MX validation. Known response classes map to: sign in again (401), unavailable action (403), changed by another person (409), marked fields (422) and temporary service failure (5xx). Entered data is preserved whenever safe.
