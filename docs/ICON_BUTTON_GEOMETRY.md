# Icon button geometry

El componente autoritativo `IconButton` fija hit area por `--nexo-touch-target` (44 px mínimo), `inline-flex`, centrado en ambos ejes, line-height 0 y SVG 20 px. X, hamburger y acciones compactas heredan hover/pressed/focus, tooltip y aria-label. El detalle de Producto dejó de renderizar el carácter `×` manual.
