# Cash Policies

Policies resolve Organization → Branch → Register and cover opening float, manual amount, mandatory/blind denomination count, tolerance, approval/withdrawal/max-drawer thresholds, shared Drawer, cashier exclusivity, refunds, negative expected balance, force-close/reopen/transfer/deposit approval, inactivity, business-day cutoff, pending-event close and future dual control. Defaults may come from onboarding, but evaluation uses persisted policy plus authorization.
