# Product Polish Performance

The generated brand image is a single project-owned raster used by login, onboarding and activation, loaded from the local Next static surface. No third-party runtime fonts, trackers or image hosts were added. Motion is CSS-only, short and disabled by reduced-motion preferences. Performance evidence records login, onboarding, Home, navigation and command-palette timings in the product-polish artifact package.

Warmed local Chromium, 10 samples, AMD Ryzen 5 3600 / 16 GiB, remeasured 2026-07-15: Login p95 101.81 ms; Home p95 189.01 ms; navigation p95 86.40 ms; command palette p95 36.30 ms. Full evidence: `artifacts/product-polish/performance.json`.
