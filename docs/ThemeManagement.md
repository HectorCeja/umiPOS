# Theme Management

## Design freeze 12.6

Dark is the single supported visual reference during owner approval. The inline bootstrap
sets it before paint and every route, portal, dialog and menu consumes the same semantic
tokens. The previous Claro/Sistema controls are temporarily removed: offering an uneven
light variant would contradict the freeze gate. This is an honest product limitation,
not a claim that the preference was saved.

Light may return only after equivalent contrast, visual-regression, responsive and human
review evidence exists. No domain, account or authorization behavior depends on theme.
