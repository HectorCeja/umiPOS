# Flutter Scene Variants

The certified set is exact: `login`, `home`, `dashboard`, `onboarding`, `catalog`, `products`, `inventory`, `sales`, `cash`, `reports`, `team`, `profile`, `settings`, `command`, `focused`, `minimal`. The enum and registry are exhaustive and tested.

Home, sales and cash use `womanpos.png`; catalog/products use `products.jpeg`; inventory uses `inventory.jpeg`; reports uses `analytics.jpeg`. Remaining variants are abstract. Login and onboarding are abstract in this package because their Web cinematic assets are not part of the authenticated Artwork Registry; no substitute is invented.
