# Component showcase

El showcase ejecutable vive en `packages/nexo_flutter_design/example`. Incluye buttons/states, inputs/selection, surfaces/cards, empty/loading, dialogs/sheets/menus y table/toolbar. Los textos indican que son fixtures visuales.

Comandos:

```bash
cd packages/nexo_flutter_design/example
flutter run -d chrome
flutter build web --release
```

Capturas y ocho videos reales de interacción/adaptación están en `artifacts/flutter-design-parity/part-2/`.
