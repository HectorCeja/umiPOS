# Component accessibility

Cobertura: roles/labels, enabled/selected/loading, 44×44, text scale 200 %, focus visible, keyboard, Escape, restore focus, barrier labels y reduced motion. Icon-only requiere label. Status/notice combina icono, copy y tono. Empty state conserva reading order.

Las pruebas no sustituyen auditoría con lectores reales. High contrast tiene golden determinista; iOS VoiceOver, Android TalkBack y lectores desktop se mantienen como validación de integración en la app POS, no como GAP del package foundation.
