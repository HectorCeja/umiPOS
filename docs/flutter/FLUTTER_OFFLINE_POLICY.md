# Offline policy

V1 final status: **FINANCIAL OPERATIONS DISABLED BY DESIGN**. Cached catalog, cart drafts, receipt cache and local diagnostics remain available; enrollment, sale, payment, finalization, cash close and external confirmation are blocked offline.

Allowed: cached catalog and local cart draft. Prohibited: enrollment, sale finalization, cash/external payment, refunds, uncached branch switch and financial sync. This conservative policy follows the absence of an offline reconciliation protocol.

# Estado V1

**STATUS: DISABLED BY DESIGN FOR V1** para toda operación financiera offline.

Se permite consultar catálogo cacheado, conservar y recuperar drafts, consultar receipts cacheados y mostrar diagnóstico. Se prohíbe crear/finalizar ventas, aceptar pagos, registrar pagos externos, ejecutar refunds, cerrar caja, enrolar dispositivos y enviar comandos financieros offline. Por tanto, NEXO V1 no requiere reconciliación financiera offline.
