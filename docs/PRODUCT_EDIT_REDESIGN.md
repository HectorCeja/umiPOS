# Product edit redesign

Se compararon tres alternativas: modal compacto (rechazado por densidad), drawer lateral (rechazado por preview limitado) y workspace modal amplio. Se eligió el workspace: conserva contexto del catálogo, ofrece preview dominante, dos columnas desktop, sheet fullscreen móvil, footer de guardado visible y una sola X oficial de 44 px. La superficie usa tokens oscuros, inputs/uploader oficiales, validación local, dirty-state y confirmación al cerrar.
