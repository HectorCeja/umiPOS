# Table Patterns

Tablas administrativas incluyen encabezados semánticos, orden anunciado, filtros persistibles, paginación de servidor, selección y bulk bar. Sticky headers no pueden ocultar foco. Personalización/exportación permanecen future-ready.

En móvil, la tabla se transforma en lista/card con nombre, estado y acción principal; el detalle tiene ruta propia. Loading conserva geometría; vacío explica cómo empezar; error preserva filtros y ofrece retry. Data sets grandes se virtualizan solo tras medición y manteniendo navegación/foco accesibles.
