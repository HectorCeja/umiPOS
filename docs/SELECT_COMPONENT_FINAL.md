# Select Component Final

La regla base única define `appearance: none`, un solo SVG no repetido, inset derecho, tamaño del
chevron, padding derecho de 48 px y padding izquierdo de 16 px. RTL invierte ambos espacios. La
certificación real se ejecutó en Inventario y la regla alcanza onboarding, Productos, Caja,
Configuración y filtros nativos.

Prueba: `select-component-final.spec.ts`.
