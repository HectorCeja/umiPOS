# 01 — Brand DNA

## Visión

NEXO hace visible y gobernable la operación de un negocio. La interfaz debe permitir que una persona entienda su estado, encuentre una acción y actúe con confianza.

## Personalidad

| Rasgo       | Expresión visual                                               |
| ----------- | -------------------------------------------------------------- |
| Precisa     | alineación, números tabulares, estados explícitos, focus claro |
| Serena      | canvas oscuro, contraste controlado, motion lento              |
| Sofisticada | profundidad localizada, tipografía editorial, detalle óptico   |
| Operativa   | navegación estable, datos primero, acciones reales             |
| Confiable   | errores honestos, permisos visibles, estados no ambiguos       |
| Viva        | auroras, artwork y halos sutiles sin ruido                     |

## Emoción objetivo

Login comunica entrada segura. Onboarding comunica progreso y construcción. Home comunica control total. Los módulos operativos comunican trazabilidad y acción. Los módulos administrativos reducen el ambiente fotográfico para favorecer concentración.

## Tono

El copy es directo, sobrio y contextual. Los títulos pueden ser editoriales; las acciones son concretas. NEXO no usa exageración, promesas de IA sin capacidad real, lenguaje gamer ni slogans decorativos.

## Posicionamiento

NEXO no es una plantilla administrativa ni una landing page dentro del producto. Es una herramienta profesional con una identidad propia. La referencia de calidad está en la precisión y coherencia del conjunto, no en copiar marcas externas.

## Límites de marca

- El violeta es acento, no un baño uniforme.
- El glow destaca jerarquía o estado, no decora todo.
- La fotografía contextualiza módulos operativos; no invade formularios administrativos.
- El negro nunca es plano: canvas, auroras, noise y vignette construyen profundidad.
- La identidad se conserva en modo estático y reduced motion.
