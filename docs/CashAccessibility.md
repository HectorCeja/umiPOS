# Cash Accessibility

Cash surfaces reuse the semantic `@nexo/ui` shell, forms, status badges, tables, alerts and timeline. The console includes a skip link, landmarks, visible labels, live status/error surfaces and keyboard-operable native controls. CSP hydration is now verified by connected browser execution.

Existing component accessibility evidence predates full connection of the console. Axe, complete keyboard journeys, 200% zoom, tablet portrait/landscape, dark mode and reduced-motion regression must be rerun before Phase 11 can close.
